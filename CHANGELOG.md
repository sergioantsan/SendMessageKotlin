# CHANGELOG

## v1.1

- Se renombraron las pantallas a `SendMessageActivity` y `ViewMessageActivity` y se alinearon los nombres de sus layouts.
- Se corrigió el tipo del botón para que coincida con el `Button` declarado en XML.
- Se conectó el envío y recepción del objeto serializable `Message`, incluyendo remitente y destinatario.
- Se separaron las etiquetas de Logcat por Activity y se actualizó la documentación del proyecto.

## v1.0

- Se completó el envío del mensaje entre las dos Activities.
- Se eliminó la barra de título automática para evitar que tapase el título de las pantallas.
- Se generó la documentación HTML del código con Dokka.
- Se añadieron el README y el manual de usuario.

## v0.1

- Se configuró el proyecto Android inicial.
- Se crearon las pantallas de envío y recepción.
- Se añadieron los recursos gráficos y los recursos de interfaz.
